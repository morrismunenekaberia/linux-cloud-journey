

# Linux & Cloud Engineering Journey

This repository documents my journey of learning Linux, software
development, DevOps, and cloud engineering.

The purpose of this repository is to record what I install, what I
learn, the commands I use, problems I encounter, and the projects I
build.

## Documentation Method

For every major tool or technology I learn, I will document:

1. What it is
2. Why I installed or learned it
3. How I installed or configured it
4. Important commands
5. What I learned
6. Problems I encountered
7. How I solved them
8. What I practiced
9. Useful resources

The goal is not just to install software but to understand what I am
doing.

## Principle

> Learn it. Use it. Document it. Build with it.
